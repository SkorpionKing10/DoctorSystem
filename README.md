# Arztpraxis-Management-System
 
Ein C# .NET-Anwendungssystem zur Verwaltung von Patientendaten, Terminen und medizinischen Dokumenten in einer Arztpraxis.
 
## Features
 
- 📋 Patientenverwaltung
- 📅 Terminplanungssystem
- 📋 Userverwaltung
## Anforderungen
 
- .NET 10.0 
- Visual Studio 2026
- SQL Server 2025
- Windows 11
## Installation
 
```bash
# Repository klonen
git clone https://github.com/username/arztpraxis.git
cd arztpraxis
 
# Dependencies wiederherstellen
dotnet restore
 
# Datenbank migrieren
dotnet ef database update
 
# Anwendung starten
dotnet run
```
 
## Verwendung
 
1. Starten Sie die Anwendung
2. Melden Sie sich mit Ihren Zugangsdaten an
3. Verwalten Sie Patienten und Termine über das Dashboard
