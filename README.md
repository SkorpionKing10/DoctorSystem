# Arztpraxis-Management-System
 
Ein C# .NET-Anwendungssystem zur Verwaltung von Patientendaten, Terminen und medizinischen Dokumenten in einer Arztpraxis.
 
## Features
 
- 📋 Patientenverwaltung
- 📅 Terminplanungssystem
- 📋 Userverwaltung
## Anforderungen
 
- .NET 10.0 
- Visual Studio 2026
- SQL Server 2025
- Windows 11
## Installation
 
```bash
# Repository klonen
git clone [https://github.com/username/arztpraxis.git](https://github.com/SkorpionKing10/DoctorSystem.git)
cd DoctorSystem

# Anwendung starten
cd Backend
dotnet run
cd Frontend
dotnet run
```
 
## Verwendung
 
1. Starten Sie die Anwendung
2. Sie werden automatisch mit Kerberos und NTML angemeldet
3. Verwalten Sie Patienten und Termine über das Dashboard
